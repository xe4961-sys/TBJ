JOMA TRACKER 2.0 - WINDOWS x64

1. EXIT the previous Fuse Timer / Joma Tracker using its tray icon.
2. Extract this ZIP. Run JomaTracker.exe. No .NET installation is required.
3. It starts hidden: press F8 (or your saved controls key) for settings.
4. Select WRECKER or GUEST. Only the selected mode runs.

WRECKER
G (default) primes the existing grenade timer:
0-3.00s countdown -> ARMED 0.20s -> RELEASE 0.50s -> BULLSEYE!! 0.30s.
Beeping stops at 3.70s; the overlay hides at 4.00s by default.
Binding, countdown duration, mute, volume and flashing remain adjustable.

GUEST - CALIBRATE FIRST
Use borderless/windowed gameplay. Show base Kick and Supportive Rush.
- Select monitor and profile name. Click Calibrate text regions.
- On the frozen screen, drag tightly around the Kick word ONLY, leaving
  enough width for Sweep/Strike. Exclude the border and LMB icon.
- Then drag around the colored Supportive/Offensive word ONLY. Exclude
  the white Rush word and F icon. The profile saves automatically.
- Check the live crops and detection labels in Guest settings.
- Click Learn Strike label, hide controls, roll in game, then press F6
  while Strike is visible. This allows white/gold Strike recognition.
- Hide controls before playing: Guest ability inputs pause in settings.

GUEST BINDS (all changeable)
Left mouse: Kick / recast       Q: Dodgeroll
F: Rush / Dropkick              F7: reset Guest windows
F6: learn Strike sample         F10: manual pickup +2s (OFF by default)
F8: open/hide controls for either mode
Bindings only observe inputs: set them to match your game.

GUEST TIMINGS
Sweep/Strike: 1.967s. Offensive availability: 2.983s, independent of Sweep.
Support: 1.550s windup -> 4s sprint; carrying hitbox starts at 1.650s.
Offensive: 0.917s windup -> 3s sprint. Safe Dropkick starts 1.050s after
Rush input and lasts to about 3.917s. Second Rush press ends the window.
Early recast is treated as cancellation. All timings are adjustable.
Guest includes shrinking bars and optional readiness beeps.
No cooldown or Enhanced Kick tracking. Reset for walls/stuns/interruptions.

Detection requires calibration and fresh screen cues. It checks 20 times/s
by default (adjustable 5-30). Lower rates save work but add latency.
The preview shows capture time; actual in-game FPS impact is not measured.
Only two text regions are captured; no video is saved or uploaded.
If the HUD is obstructed or uncertain, Rush can show UNCONFIRMED.

COMMON
Position overlay: drag its text, then click Done positioning to lock it.
Hide controls/F8/close minimizes to the tray. Exit app/tray Exit quits.
Sound on and volume affect both modes. Test sound and Windows mixer help
check audio. Previous Wrecker settings are retained.

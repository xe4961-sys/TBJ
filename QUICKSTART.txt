JOMA QOL 3.0.0 - WINDOWS x64

1. EXIT the previous Fuse Timer / Joma Tracker / Joma QoL using its tray icon.
2. Extract this ZIP. Run JomaQoL.exe. No .NET installation is required.
3. It starts hidden: press F8 (or your saved controls key) for settings.
4. Select WRECKER or GUEST. Only the selected mode runs.

CHARACTER SWITCHER (3.0.0)
F8 -> Switcher. Defaults: Numpad 1 Brawler, 2 Knight, 3 Guest,
4 Firefighter, 5 Unassigned. Record each favorite separately.

1. Select a favorite and click Record selected. Settings hide.
2. Return to game with the Shop CLOSED (the starting state to reuse).
3. Press F9 to BEGIN. Click Shop -> character -> Equip normally.
4. Release mouse buttons. Press F9 again to SAVE. Escape cancels.
5. Open F8 -> Switcher, enable Numpad 1-5 shortcuts, then hide controls.
6. Return to that same game/menu state. NUM LOCK ON, use the Numpad key.

F9 recording key and favorite names are changeable.
Replay defaults to 200% speed, minimum 150ms between menu actions.
Increase minimum wait / lower speed if menus miss clicks. Optional per-step
recorded wait editing is in the action list; first action is immediate.
Escape, F8/opening controls, or tray Stop macro stops replay.
Focus/window-size changes abort; queued/repeated replays are not allowed.
Only clicks/wheel are recorded, not typing or mouse drag paths.
Moving the window is supported; resizing/menu layout changes need rerecording.
The switcher works alongside Wrecker/Guest; tracker inputs pause during macros.
Only the recorded app with controls hidden can use its shortcut.
Successful click dispatch does NOT confirm that the game equipped a character.
Native Windows recording/hotkeys/replay still need testing on your PC.
Previous tracker settings/calibration and Wrecker sounds are retained.

OPTIONAL VISUAL EVENTS (2.0.5)
In Guest, scroll to OPTIONAL VISUAL EVENTS. Both options start OFF.
First calibrate the normal Kick/Rush profile at your current resolution.

SWEEP: Click Capture Sweep XP in 3s. Hide settings happens automatically;
land Sweep during the delay. On the frozen screen, select only the white
words Landed Sweep. (exclude all XP/point numbers), then the XP search area
including the rows where it moves. Enable Refresh Offensive on Landed Sweep XP.
A newly detected event after an attack refreshes Offensive availability;
it does not extend an already active Rush. Lingering/moving text is deduplicated.
Missed/hidden/replaced-in-place messages may be missed. Timing starts when
we first see the XP message, not at the actual hit. Different bonuses do
not matter when only the words were selected.

PICKUP (EXPERIMENTAL): Click Capture red Rush box in 3s, initiate Supportive
Rush during the delay, then select a region containing the red box sides.
Enable Experimental passenger detection. Hide controls, start a new Rush.
Requires red presence after 1.65s, followed by sustained disappearance.
Adds +2s at most once; PICKUP? means assumed, not confirmed.
Wall collisions, camera turns, occlusions and other red objects can fool it.
Disappearance near the expected end is ignored. Reset after a wall/stun.
Keep regions under 200,000 pixels. Calibration is saved in the profile.
Extra checks target at most 10/s; main ability settings are unchanged.
Hide controls/F8 before gameplay inputs. See README for exact safeguards.

COMPACT DISPLAY (2.0.4)
Enable Compact display in the common settings for minimal text and no bars.
Guest combines Rush time/phase and independent windows into fewer lines.
Wrecker uses a smaller countdown/warning display. Saved; optional.
Optional experimental passenger / Landed Sweep XP detectors are described above.

WRECKER

RAPID KICK -> RUSH FIX (2.0.3)
Fast Kick checks briefly target up to 60/s for 0.4s; optional in Guest settings.
A confirmed Sweep can also confirm a landed hit for offensive Rush selection.
A one-time Rush-region check and brief early recovery catch late hit cues,
keeping the original input time. Kick input alone is never a confirmed hit.
The normal steady rate remains adjustable 5-30/s.

DAMAGE-TINT FIX (2.0.2)
Colors are compared against nearby background to reject red damage washes.
Existing calibration is retained; no capture-rate increase is needed.
Severely hidden text may show Unknown rather than a guessed variant.

GUEST - TEST THE OVERLAY FIRST
Test supportive Rush / Test offensive Rush show simulated timers without
calibration. Controls hide; press F8 to return. They do not activate moves.
Sprint duration is a separate line beside WAIT / DROPKICK READY.

GUEST - CALIBRATE FOR LIVE DETECTION
Use borderless/windowed gameplay. Show base Kick and Supportive Rush.
- Select monitor and profile name. Click Calibrate text regions.
- On the frozen screen, drag tightly around the Kick word ONLY, leaving
  enough width for Sweep/Strike. Exclude the border and LMB icon.
- Then drag around the colored Supportive/Offensive word ONLY. Exclude
  the white Rush word and F icon. The profile saves only after a green/red Rush cue is recognized.
- Check the live crops and detection labels in Guest settings.
- Click Learn Strike label, hide controls, roll in game, then press F6
  while Strike is visible. This allows white/gold Strike recognition.
- Hide controls before playing: Guest ability inputs pause in settings.

GUEST BINDS (all changeable)
Left mouse: Kick / recast       Q: Dodgeroll
F: Rush / Dropkick              F7: reset Guest windows
F6: learn Strike sample         F10: manual pickup +2s (OFF by default)
F8: open/hide controls for either mode
Bindings only observe inputs: set them to match your game.

GUEST TIMINGS
Sweep/Strike: 1.967s. Offensive availability: 2.983s, independent of Sweep.
Support: 1.550s windup -> 4s sprint; carrying hitbox starts at 1.650s.
Offensive: 0.917s windup -> 3s sprint. Safe Dropkick starts 1.050s after
Rush input and lasts to about 3.917s. Second Rush press ends the window.
Early recast is treated as cancellation. All timings are adjustable.
Guest includes shrinking bars and optional readiness beeps.
No cooldown or Enhanced Kick tracking. Reset for walls/stuns/interruptions.

Detection requires calibration and fresh screen cues. It checks 20 times/s
by default (adjustable 5-30). Lower rates save work but add latency.
The preview shows capture time; actual in-game FPS impact is not measured.
Two text regions plus any enabled extra regions are captured; no video is saved or uploaded.
If Rush is persistently Unknown before input, live timers cannot start. Select the colored
Supportive/Offensive prefix, not just white Rush or the entire card.
Rush now latches a fresh green/red cue at input, so the ability cards
disappearing during windup will not cancel its timer. Wait for the first
confirmed color before using Rush. The preview reports the last input.
Positioning pauses detection; overlapping timer text is moved clear of
the ability labels when positioning ends.

FUSE TIMER 1.2.2 - WINDOWS x64

UPDATING: Exit the OLD copy from its tray icon first. Then extract this ZIP
and run the NEW FuseTimer.exe. No .NET installation is required.

The app STARTS HIDDEN. There is no settings/taskbar window until you ask.
- G (default): start or restart the grenade countdown.
- F8 (default): open/hide settings.
- Clock icon in the system tray: open settings, mute, pause, or exit.

SEQUENCE AFTER THE GRENADE KEY
0.00-3.00 seconds: floating countdown with accelerating electronic beeps.
3.00-3.20 seconds: ARMED, with urgent high-pitched beeps.
3.20-3.70 seconds: RELEASE!, with urgent high-pitched beeps.
3.70-4.00 seconds: BULLSEYE!! airburst cue; warning audio stops.
After 4.00 seconds: the overlay hides by default.
There is no added explosion sound or spoken voice.

SETTINGS (press F8)
- Change the grenade key or the separate controls key. Click Change key,
  release the mouse/keys, then press the new key. Escape cancels capture.
  The two keys must differ. Supports one key or Mouse middle/4/5, no chords.
- Sound on/muted and volume: affect ALL countdown and warning beeps.
- Test sound: cancels the countdown and plays a longer beep. It uses the
  selected mute/volume and reconnects to the default Windows audio device.
  Any Windows audio error appears below the button.
- Windows mixer: opens Windows volume/output settings. If the sound test is
  silent, check FuseTimer is unmuted there and uses your speakers/headphones.
- Only show while primed: ON by default. Hides the idle/completed overlay.
- Gentle warning flashes: optional, OFF by default. Only the ARMED/RELEASE
  text pulses; it never flashes the whole screen or goes fully invisible.
- Position overlay: shows a movable preview. Drag the digits, then choose
  Done positioning. During play the overlay is click-through.
- Hide controls or F8 returns to hidden/background mode. Closing the
  settings window also hides it. To stop the app, choose Exit app or tray Exit.

The overlay has a transparent background, no title bar or border, no taskbar
button, and does not activate or take focus from the game. Use borderless
fullscreen or windowed mode; exclusive fullscreen may cover ordinary overlays.

Holding the grenade key starts one sequence. Release and press again to
restart from 3.00. The app observes the key without blocking/replaying it.
Hotkey enabled can be turned off; manual Start still works for testing.

Settings, binding, mute, and overlay position are saved under:
%LOCALAPPDATA%\FuseTimer\settings.json
If F8 was your old grenade key, the controls key defaults to F9 instead;
the tray icon always provides access.

This is a manual timing aid, not a game integration or detonation detector.
The deadline is based on the observed key press. Change Seconds until ARMED
if calibration is needed; ARMED remains 0.20s, RELEASE 0.50s, and BULLSEYE!! 0.30s.

TEST BUILD: Windows x64, self-contained, unsigned. Timing, visibility rules,
key-edge logic, and PCM beep data passed 25 tests on Linux. The executable
compiled for Windows; native transparency, key input, and speaker output
still need testing on your Windows PC.
